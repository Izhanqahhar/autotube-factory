# Model Hub

Signed-in web desk for OpenAI, Claude, Grok, Kimi, Gemini, DeepSeek, Groq, Mistral, OpenRouter, and Together.

Bind provider API keys in Cursor Secrets. Until a key is set, chat returns clearly labeled sample replies.

```bash
npm install
npm run dev
```

Open `http://127.0.0.1:3000`. Local identity is simulated until the app is published as private or team.
